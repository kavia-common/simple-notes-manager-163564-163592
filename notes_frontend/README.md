# Notes Frontend (Remix)

Features:
- User authentication (signup, login, logout)
- CRUD for notes
- Search and filter by tags
- Responsive sidebar/main layout
- Tailwind CSS, light theme

Environment:
- Copy `.env.example` to `.env` and set `NOTES_API_BASE_URL` to your notes_db backend.

Development:
- npm install
- npm run dev

Build:
- npm run build
- npm start
